# Barkpocalypse

Portrait-first idle merge-shooter RPG: dog guardians auto-fire at zombies and robots, merge duplicate weapons up a 13-rung historical ladder, and layer multiplicative progression systems.

Stack: Vite + React + TypeScript, Canvas renderer, procedural Web Audio. The sim is separate from rendering (`src/game/sim.ts` vs `render.ts`).

```
npm install
npm run dev
```

## Status
Slice 1: combat sim, 13-rung weapon ladder + merging, 4 guardians (Rudy, Cooper, Bruno, Luna), biome backgrounds, procedural audio, saves.
